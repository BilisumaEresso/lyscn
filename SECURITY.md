# Security Policy

## Supported Versions

Only the latest release running on the `main` branch receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of LayoScan seriously. If you believe you have discovered a vulnerability, please follow coordinated disclosure guidelines:

1. **Do not disclose publicly**: Do not create public GitHub issues or forum posts describing the vulnerability.
2. **Email disclosure**: Send full technical details, reproduction steps, and potential impact to `security@layoscan.com` (or create a private GitHub Security Advisory).
3. **Acknowledgment & Timeline**:
   - We aim to acknowledge reports within **48 hours**.
   - An initial triage assessment and proposed remediation plan will be provided within **5 business days**.
   - A patched release will be deployed to production before details are disclosed.

## Safe Harbor

Activities conducted in good faith under this policy will be considered authorized conduct:
- Do not exploit vulnerabilities beyond the minimum necessary to demonstrate proof-of-concept.
- Do not compromise customer data, alter production state unnecessarily, or perform denial-of-service testing against production servers.
